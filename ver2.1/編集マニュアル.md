## 2. 問題を追加する

該当する章のファイル（例：2章なら `questions/ch02.js`）を開き、最後の問題の `},` の後ろに追加します。
書き方は2種類あります。

### 書き方A：シンプル形式（文章 → コード）

```js
{
    id: 20,
    chapter: "ch02",
    text: "次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。(1つ選択)",
    code: `1. public class Main {
2.     public static void main(String[] args) {
3.         System.out.println("Hello");
4.     }
5. }`,
    options: `A. Helloが表示される
B. コンパイルエラーが発生する`,
    answer: "A",
    explanation: `ここに解説を書く。`
},
```

### 書き方B：contents 形式（文章・コード・メモリンク・画像を自由な順番で並べる）

```js
{
    id: 21,
    chapter: "ch02",
    contents: [
        { type: "text", value: "問題文をここに書く" },
        { type: "code", value: `1. public class Main { }` },
        { type: "text", value: "[memo:indexof:indexOf()]" },
        { type: "image", src: "image/2_21.png", alt: "問題の図" },
    ],
    options: `A. 選択肢1
B. 選択肢2`,
    answer: "A",
    explanation: `ここに解説を書く。`
},
```

`contents` に書けるもの：

| type | 中身 | 用途 |
|---|---|---|
| `text` | `value: "文章"` | 問題文。メモリンクも書ける |
| `code` | `value: \`コード\`` | コード表示 |
| `image` | `src: "image/ファイル名"`, `alt: "説明"` | 画像表示 |
| `math` | `value: "数式"` | 数式表示（KaTeX） |

> `contents` を書いた問題では `text` と `code` は無視されます。どちらか片方の形式で書いてください。

### 各項目の意味

| 項目 | 意味 | 注意 |
|---|---|---|
| `id` | 問題番号 | 同じ章の中で重複しないように |
| `chapter` | 章の番号 | `"ch01"` 〜 `"ch12"`。ファイルと合わせる |
| `options` | 選択肢 | 1行に1つ |
| `answer` | 正解 | **書き忘れると「正解：」が空になる** |
| `explanation` | 解説 | メモリンクも書ける。改行はそのまま反映される |

## 3. メソッドメモへのリンクを付ける

### 書き方

```
[memo:メモのid:画面に表示する文字]
```

例：`[memo:indexof:indexOf()]` → 「indexOf()」というリンクが表示され、クリックするとメソッドメモの `id: "indexof"` の項目へ飛びます。

### 書ける場所

- `text`（シンプル形式の問題文）
- `contents` の `{ type: "text", value: "..." }`
- `explanation`（解説）

### 例：シンプル形式の問題の解説にリンクを付ける

```js
explanation: `indexOf() メソッドは、指定した文字列が最初に登場するインデックス番号を返します。
対象の文字列の中に指定された文字列が存在しない場合、例外はスローされず -1 を返します。
[memo:indexof:indexOf()]`
```

### 注意

- 「メモのid」は `methods.js` の `id` と**完全に一致**させる（大文字・小文字も区別される）。
- メモのidに `:`（コロン）や `]` は使えない。
- `code` の中に書いてもリンクにはならない（ただの文字として表示される）。

## 4. メソッドメモを追加する

`methods.js` を開き、最後の `},` の後ろに追加します。

```js
{
    id: "length",
    title: "String.length()",
    content: `
- **説明**: 文字列の長さ（文字数）を返す。
- **注意**: 配列の場合は length（カッコなし）。
- **問題**: 2章15問`
},
```

| 項目 | 意味 |
|---|---|
| `id` | リンクで使う名前。**他のメモと重複させない** |
| `title` | メモの見出し |
| `content` | 本文。`**太字**`、`` `コード` `` が使える。改行はそのまま反映 |

1. `questions/ch13.js` を作り、1行目〜2行目に次を書く。

   その後に問題を並べ、最後を `);` で閉じる（他の章ファイルと同じ形）。

   ```js

   ```

   ```html
   <script src="questions/ch13.js"></script>
   ```

## 7. うまく表示されないとき

画面が真っ白・問題が出ないときは、ほぼ書き間違いです。

1. ブラウザで **F12** → 「Console（コンソール）」タブを開く。
2. 赤いエラーに `ch02.js:280` のように**ファイル名と行番号**が出るので、そこを確認する。

よくある書き間違い：

- 問題と問題の間の `},` の `,` が抜けている
- `` ` ``（バッククォート）や `"` を閉じ忘れている
- 文章の中で `` ` `` を使ってしまった（バッククォートで囲んだ文字列の中では `` \` `` と書く）
- `contents: [ ... ],` の `]` を閉じ忘れている
- メモリンクの id が `methods.js` と一致していない（エラーは出ず、クリックしても飛ばないだけ）
